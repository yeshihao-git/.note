# windows 注册表

**what**：
windows 的配置数据库，用于保存操作系统、软件、用户和硬件的各种配置信息

|配置信息|示例|
|---|---|
|系统设置|开机启动项、系统行为|
|软件设置|软件安装路径、运行参数|
|用户设置|桌面、文件夹显示偏好|
|右键菜单|右键某个文件时显示哪些菜单项|
|文件关联|双击 `.java` 文件时使用哪个程序打开|

**常见注册表根键**：

| 根键                          | 作用                  |
| --------------------------- | ------------------- |
| `HKEY_LOCAL_MACHINE`（HKLM）  | 整台计算机的系统和软件配置       |
| `HKEY_CURRENT_USER`（HKCU）   | 当前登录用户的配置           |
| `HKEY_CLASSES_ROOT`（HKCR）   | 文件关联、组件注册、Shell 菜单等 |
| `HKEY_USERS`（HKU）           | 各用户配置文件对应的注册表数据     |
| `HKEY_CURRENT_CONFIG`（HKCC） | 当前硬件配置相关信息          |
