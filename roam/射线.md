## 浏览器坐标转NDC坐标

浏览器坐标
```
	 浏览器 Canvas 坐标

	  y=0
	   ↓
(0,0) ┌────────────────┐ (width,0)
	  │                │
	  │                │
	  │       O        │
	  │                │
	  │                │
	  └────────────────┘
(0,height)     (width,height)

		 x →

x ∈ [0, canvas.width]
y ∈ [0, canvas.height]
```

webgl剪裁空间的NDC坐标
```
		 NDC 坐标系
		 
			 y = 1
			   ↑
			   |
			   |
  (-1,1)       |        (1,1)
	 ┌─────────┐
	 │         │
	 │         │
	 │    O    │
	 │         │
	 │         │
	 └─────────┘
  (-1,-1)      |        (1,-1)
			   |
			   ↓
			 y = -1

x ∈ [-1, 1]
y ∈ [-1, 1]
z ∈ [-1, 1]
```

浏览器坐标转NDC坐标
```ts
const ndcX = ((event.clientX - canvas.left) / canvas.width) * 2 - 1;
const ndcY = -(((event.clientY - canvas.top) / canvas.height) * 2 - 1);
```

## NDC近/远平面坐标转换为对应的世界坐标

```ts
/* NDC 点
-> 构造齐次裁剪坐标 (x_ndc, y_ndc, z_ndc, 1)
-> 乘 inverse(P * V)
-> 得到齐次世界坐标 (x, y, z, w)
-> 除以 w
-> 世界坐标点
*/
setFromCamera(ndcX: number, ndcY: number, camera: Camera): void {
// 逆VP变换矩阵
this.projectionViewMatrix.multiplyMatrices(camera.projectionMatrix, camera.viewMatrix);
this.inverseProjectionViewMatrix.copy(this.projectionViewMatrix).invert();

// NDC近平面的点应用矩阵变换（MVP逆矩阵）
// applyMatrix4 作用：对三维向量应用矩阵变换，即乘 inverse(P * V) -> 除以 w
const nearPoint = new Vector3(ndcX, ndcY, -1).applyMatrix4(this.inverseProjectionViewMatrix); 
// NDC远平面的点应用矩阵变换（MVP逆矩阵）
const farPoint = new Vector3(ndcX, ndcY, 1).applyMatrix4(this.inverseProjectionViewMatrix);

// 构造射线：P(t) = origin + direction * t
this.origin.copy(nearPoint);
this.direction.copy(farPoint).sub(nearPoint).normalize();
}
```

## 射线与包围球相交检测

```ts
  /**
   * 检测射线是否与 Mesh 的世界空间包围球相交。
   * 射线：P(t) = origin + direction * t
   * 包围球：center = 模型中心
            radius = 包围球半径
   */
  intersectMesh(mesh: Mesh): RaycastHit | null {
    const e = mesh.worldMatrix.elements;
    const center = new Vector3(e[12], e[13], e[14]); // 包围球中心（模型中心）
    const radius = mesh.geometry.boundingRadius * this.getMaxWorldScale(mesh); // 包围球半径
    const toCenter = center.sub(this.origin); // 射线起点指向球心的向量
    const projectedDistance = toCenter.dot(this.direction); // 球心投影到射线方向上的点与射线起点之间的距离

    // 不命中：包围球在射线背后
    if (projectedDistance < 0) {
      return null;
    }

    const distanceSquared = toCenter.dot(toCenter) - projectedDistance * projectedDistance; // 球心到射线的垂直距离：勾股定理

    // 不命中：垂直距离 > 球半径
    if (distanceSquared > radius * radius) {
      return null;
    }

    // 命中：垂直距离 < 球半径
    const offset = Math.sqrt(radius * radius - distanceSquared); // 球心在射线上投影的点与 射线和包围球第一次触碰的点 之间的距离

    // 射线 origin ---- hit1 ---- projection ---- hit2 ---->
    //                          |
    //                          | 垂直距离
    //                          |
    //                        球心 center
    
    return {
      object: mesh,
      distance: projectedDistance - offset, // 射线起点与射线和包围球第一次触碰的点 之间的距离
    };
  }
```
