### 纵向箭头流程  
  
```  
用户输入账号密码  
      ↓  
POST /api/login  
      ↓  
用户服务校验账号密码  
      ↓  
查询 user 表  
      ↓  
验证成功  
      ↓  
生成 Token  
      ↓  
返回 Token + 用户信息  
      ↓  
前端保存 Token  
      ↓  
访问其他接口时携带 Token  
```
