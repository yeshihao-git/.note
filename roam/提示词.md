# 提示词
## 软件需求与设计文档
### PRD

```
我想做一个个人网站，希望实现的功能点如下： 登录注册 
网站上方有两个模块：首页、随记、片刻（首页类似看板，会有各项记录；随记里面存放自己的笔记；片刻类似博客可以实时写一些内容上去） 

你根据以上内容分析需求、并对我进行追问，后续我们会生成初版prd
```

## 项目架构设计
### 前端

1. 技术栈为 ts、vue 组合式api
2. 前端采用微前端架构设计，主应用、子应用使用 iframe
3. 保持代码可读性，给代码加上注释，注释应当保持简短即6个字以内
4. CSS语义化 + 字体样式统一管理，基础字号如下：
```
--{xx}-font-2xs-size: 10px;  
--{xx}-font-xs-size: 12px;  
--{xx}-font-ss-size: 13px;  
--{xx}-font-sm-size: 14px;  
--{xx}-font-base-size: 16px;  
--{xx}-font-lg-size: 18px;  
--{xx}-font-xl-size: 20px;  
--{xx}-font-2xl-size: 24px;
```

```

      ↓  
POST /api/login  
      ↓  
用户服务校验账号密码  
      ↓  
查询 user 表  
      ↓  
验证成功  
      ↓  
生成 Token  
      ↓  
返回 Token + 用户信息  
      ↓  
前端保存 Token  
      ↓  
访问其他接口时携带 Token  
```
