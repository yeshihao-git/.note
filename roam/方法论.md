# 方法论
## 通用方法论

**主动回忆学习法**（检验记住了多少）
1. 看完一篇内容就复述下讲了啥

**费曼学习法** （检验理解深度）
1. 和豆包AI对话：以输出倒逼输入，“教小学生” 的场景，强迫自己用简单语言拆解复杂知识，使用 结构学习法 ：`what + why + how` 讲述知识
2. 用贴近生活的例子辅助讲解：检验对知识本质的理解
3. 核心循环：输出讲解→暴露知识盲点 / 模糊点→查阅资料修正认知→再次输出讲解，循环直至能让新手轻松听懂，最终实现从 “记住知识” 到 “掌握知识” 的转化

## 代码方法论

**调试学习**
1. 通过 debug 的方式理解代码的逻辑调用关系

**学习性测试**（学习第三方库 API）
1. 编写测试代码来理解第三方库的 API
2. 学习结束后，将第三方库 API 封装到自己的类中（可以使用 [[适配器模式#适配器模式|适配器模式]]）

> 相比直接使用 第三方库 API，将第三方库 API 封装为类后使用更易于统一的维护管理

**代码重写**
1. （代码量小的情况）通过 ==全部重写== 第三方代码库的方式来学习代码
2. （代码量大的情况）通过 ==局部重写== 第三方代码库的方式来学习代码

## 高效学习方法论
### 费曼技巧（Feynman Technique，加州理工学院）
#### 核心操作
当学习内容理解模糊时，立刻停止看书接收信息；设想向完全零基础的外行讲解该知识点，全程用大白话表述。如果讲解中途卡壳、被迫使用专业术语，就代表自身理解存在漏洞，返回资料重新钻研对应部分，直到可以通俗讲透。
#### 适用场景
梳理编程原理、图形学算法、技术框架底层逻辑，检验自己是否真的吃透知识点，而非单纯记住术语。

### 主动提取效应（Active Recall，华盛顿大学）
#### 核心操作
备考、学习陌生领域知识时，不要反复通读教材、勾画重点这类低效率操作；读完一小节内容后合上资料，拿白纸默写核心概念、逻辑链路。大脑主动回忆调取知识，记忆留存率远高于被动阅读。
#### 适用场景
背诵API、数学公式、图形学理论、代码架构设计思路。

### 间隔重复法（Spaced Repetition，加州大学圣地亚哥分校）
#### 核心操作
大量需要记忆的内容不要考前突击背诵；借助Anki这类卡片工具，在记忆即将淡忘的节点安排复习，用很少的复习次数，把短期记忆转化为长期记忆。
#### 适用场景
专业名词、语法、接口参数、几何基础、行业规范这类需要长期储备的细碎知识。

### 交替学习法（Interleaving Practice，加州大学洛杉矶分校）
#### 核心操作
练习成套复杂技能时，不要长时间单一练习某一个模块；穿插不同类型的学习内容、练习项目，强迫大脑切换思维逻辑。初期做题、写代码会觉得不顺手，但实战中知识调用速度会大幅提升。
#### 适用场景：
比如同时学习`VTK.js`、GLSL、C++、工业几何知识，每天穿插练习，不要一整天只啃单一板块。

### 睡眠固化记忆（Sleep Consolidation，哈佛大学医学院）
#### 核心操作
遇到难以攻克的难题，不必熬夜死磕；睡前集中精力梳理问题、整理已知条件，之后正常深度睡眠。睡眠期间大脑会整理白天接收的信息、重组神经连接，睡醒后常常能想到新的解题思路，同时完成知识记忆加固。
#### 适用场景：
调试复杂渲染bug、推导算法、构思项目架构。

### 执行意图公式（Implementation Intentions，纽约大学）
#### 核心操作

想要养成学习习惯、克服拖延，不要依靠意志力打气；编写精准的`如果XX情况发生，我就执行XX行动`的触发规则，依托环境触发行为，绕过内心的拖延纠结，自动开启学习。
举例：如果晚饭后收拾完碗筷，我就花90分钟学习工业可视化相关技术。
#### 适用场景：
制定下班后自学编程、图形学的长期计划，稳定维持学习节奏。
