# 消息总线 

**what**：
EventBus，核心是发布 - 订阅（Pub/Sub）：
1. 总线维护一张 `事件名 = 回调函数数组` 的映射表
2. 发送方：`bus.emit('事件名', 参数)` 广播
3. 接收方：`bus.on('事件名', 回调)` 提前注册监听
4. 发送者不知道谁会接收，接收者不知道谁发送，完全解耦

```javascript
// 核心：事件名 = 回调函数数组
class EventBus {
  constructor() {
    this.events = {}; // { 事件名: [回调函数, ...] }
  }

  // 接收方：提前注册监听（对应第 3 点）
  on(event, callback) {
    (this.events[event] ||= []).push(callback);
  }

  // 发送方：广播（对应第 2 点）
  emit(event, ...args) {
    (this.events[event] || []).forEach(cb => cb(...args));
  }

  // 随时取消订阅（对应"典型特征"）
  off(event, callback) {
    this.events[event] = (this.events[event] || []).filter(cb => cb !== callback);
  }
}

// ---- 使用示例 ----

const bus = new EventBus();

// 组件 A（接收方）
bus.on('userLogin', (user) => {
  console.log('欢迎,', user.name);
});

// 组件 B（接收方），可随时取消
const onLogout = () => console.log('已退出');
bus.on('userLogout', onLogout);
bus.off('userLogout', onLogout); // 取消后不再触发

// 组件 C（发送方），完全不知道谁在监听
bus.emit('userLogin', { name: '张三' });
```
