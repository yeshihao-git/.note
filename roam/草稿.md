# spec

你说：
```
我要做一个CAD拉伸功能
```

这只是需求：
```
Need:
支持拉伸
```

但是 spec 会具体化：
```
Extrude Feature Specification


输入:
- Profile
- Distance
- Direction


输出:
- Solid


约束:
- Distance > 0
- 支持Undo


接口:

class ExtrudeCommand {
 execute()
 undo()
}
```
